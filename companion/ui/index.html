Set up SlideRelay

A few one-time steps. SlideRelay then lives in the menu bar.

  1. Add SlideRelay to PowerPoint

    Puts a Broadcast button on PowerPoint's Home tab.

    Done. Quit and reopen PowerPoint, then click Home → Broadcast.

  2. Let PowerPoint connect

    Lets PowerPoint talk to SlideRelay securely on this Mac. macOS asks for your Mac password once.

    Done.

  3. Allow Screen Recording

    Lets SlideRelay see your slideshow window (and only that window). Switch SlideRelay on, then reopen SlideRelay if macOS asks.

    Done.
